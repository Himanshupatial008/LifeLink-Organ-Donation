# LifeLink — Organ Donation Awareness & Registration Portal

A responsive front-end college project built with HTML, CSS and vanilla JavaScript.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser. No installation is required.

## Features
- Responsive landing page and navigation
- Organ donation awareness content
- Organ/tissue information cards
- Four-step process overview
- FAQ accordion
- Donor-interest demo form with validation and consent checkbox
- Saves demo entries to browser `localStorage`

## Important project limitation
This is an educational demonstration, NOT an official donor registry. The form does not register anyone legally or transmit information to an organisation. Avoid entering sensitive personal or medical information. For official guidance in India, consult NOTTO: https://notto.mohfw.gov.in/

## Suggested future improvements
- Backend API and database with secure authentication
- Admin dashboard and consent audit trail
- Official registration integration only with authorised approval
